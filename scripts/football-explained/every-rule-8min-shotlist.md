# Every Football Rule Explained In 8 Minutes — Script + Motion Prompts (Shot List)

Production-ready shot list. Each shot has the **spoken line (VO)**, a **motion prompt**
for AI video generation, and its **duration**. Total runtime ≈ **8:02**.

## How to use
- Generate each shot from its motion prompt (e.g. Higgsfield `generate_video`).
- Prepend the **GLOBAL STYLE** to every prompt for visual consistency.
- Reuse the **NARRATOR** description verbatim wherever the presenter appears so the
  character stays consistent across shots.
- VO timing assumes ~2.5 words/sec. Trim/extend clips to match the recorded VO.

**GLOBAL STYLE (prepend to every prompt):**
> 3D-rendered bright high-saturation cartoon explainer style, clean minimalist studio,
> soft global illumination, bold flat colors, smooth 24fps motion, energetic and friendly.

**NARRATOR (reuse for every presenter shot):**
> the same friendly animated male presenter — tan skin, short dark hair, black zip-up
> sweater — standing beside a white whiteboard in a bright minimalist room.
